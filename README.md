# Traffic Risk Analyzer

A data analysis project exploring accident severity and road safety patterns using the UK Road Safety Dataset.

## Project Overview

This project was carried out as part of a team mini-project for the Data Preprocessing and Exploratory Data Analysis (EDA) Lab. The goal was to analyze a large real-world road accident dataset and understand how different factors such as speed limits, weather conditions, road types, and traffic conditions influence accident severity.

The project involved cleaning and preparing the dataset, exploring patterns through visualizations, and applying machine learning techniques to better understand accident-related trends.

## Dataset

* UK Road Safety Dataset
* More than 1.5 million accident records
* Includes information about accident severity, casualties, vehicles involved, weather conditions, road conditions, speed limits, and other related factors

## What the Project Covers

* Data Cleaning and Preprocessing
* Missing Value Handling
* Outlier Detection
* Feature Engineering
* Exploratory Data Analysis (EDA)
* Data Visualization
* Correlation Analysis
* Linear Regression
* Random Forest Regression

## Key Insights

Some observations from the analysis:

* Most accidents in the dataset were classified as slight accidents.
* Speed limits showed a noticeable relationship with accident severity.
* Weather and road conditions influenced accident outcomes.
* Traffic patterns during rush hours and nighttime revealed interesting trends.
* Data preprocessing significantly improved the quality of analysis.
